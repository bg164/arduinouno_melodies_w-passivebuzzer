# arduinouno_melodies_w-passivebuzzer
This repository provides ready-to-use .ino files that allow you to play 8-bit melodies using an Arduino Uno and a passive buzzer.


  Buzzer Signal Pin           (+ / VCC):     Connect to D8 (Digital Pin 8) on the Arduino Uno.         
  Buzzer GND / Negative Pin      (-):        Connect to one of the GND pins on the Arduino Uno

  Buzzer (+)  ---> Arduino Digital Pin 8        
  Buzzer (-)  ---> Arduino GND
